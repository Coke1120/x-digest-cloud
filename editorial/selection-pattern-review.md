# Optional private selection-pattern review

A source-pattern review is separate from news selection. The operator must explicitly configure its public source URL, cadence and private state destination outside this public template.

1. Read the private last-success and last-attempt state. Respect the configured review and retry intervals.
2. Retrieve at most three recent public editions without Site credentials, X cookies or repository credentials.
3. Record observable author, category, language, evidence and duplication patterns. Mark uncertain roles unknown and self-reported funnel numbers as self-reported.
4. Separate observations from inferred choosing rules. Public summaries do not establish hidden ranking, follow lists, accuracy or causal selection rules.
5. Compare with private source-quality notes and retain a few qualified hints with observed dates and URLs.
6. Save compact findings only to the configured private store with concurrency protection and readback. If unavailable, preserve previous findings and the successful date; record a safe attempt failure privately.

Never copy another digest's prose, use it as publication evidence, automatically promote authors, change credentials/audience/schedules, or recreate private reports in this public repository.
